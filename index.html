JARVIS RECOVERY — Chat and tasks work locally. AI installation is blocked when opened as a downloaded HTML file. Host this app over HTTPS before installing the CPU-only model. GPU initialization is disabled after the Android Chrome crash. You may also host JARVIS to use the native llama.cpp runtime and your GGUF model. This portable file initially needs internet to fetch the runtime and weights. Do not place secrets in HTML. Export before switching browsers.
JARVIS needs a web server to load this version. If the buttons do not respond, do not open index.html in a ZIP, file preview, or via file://. Run npm start and open http://127.0.0.1:3000, or deploy to Firebase Hosting. For a directly openable version, use jarvis-offline.html.
